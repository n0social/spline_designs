# spline_designs

Portfolio web experiments combining **Three.js** (procedural graphics) and **Spline** (3D scenes where noted).

## Interactive wave (`interactive-wave/`)

Black hero with two dotted sine waves (white front, grey rear) flowing left to right, centered **Welcome** text fading inward.

```bash
cd interactive-wave
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).
