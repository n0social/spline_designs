# spline_designs

Portfolio web experiments combining **Three.js** (procedural motion) and future **Spline** scenes.

## Interactive wave — Welcome

Black full-screen hero with two dotted sine waves (bright white above, muted grey below) flowing left to right, plus centered **Welcome** text that fades inward.

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).
